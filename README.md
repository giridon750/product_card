# 🛒 Product Card React

A responsive product card and shopping cart interface built using **React.js** and **Tailwind CSS**.

## 🚀 Features

* Display multiple product cards
* Product quantity increase/decrease
* Delete products from the cart
* Dynamic product count
* Order Now functionality
* Automatic subtotal calculation
* Tax calculation
* Delivery charge calculation
* Total price calculation
* Coupon code section
* Responsive design for mobile, tablet, and desktop

## 🛠️ Technologies Used

* React.js
* JavaScript
* Tailwind CSS
* HTML
* CSS
* Vite
* Font Awesome

## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/giridon750/product_card.git
```

Go to the project folder:

```bash
cd product_card
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
